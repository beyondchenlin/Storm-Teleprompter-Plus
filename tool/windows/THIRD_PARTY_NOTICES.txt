2. Microsoft Visual C++ Runtime（微软 C++ 运行库）
安装包采用应用目录内部署方式，包含来自 Microsoft Visual Studio（微软开发工具）
官方 VC/Redist/MSVC/x64 再分发目录的运行库。文件保持原始微软数字签名，
不从系统目录复制，不注册为全系统组件，也不需要管理员安装运行库。
具体文件、版本和校验值记录在 bk-build-receipt.json（构建凭据）及产品文件清单中。
相关部署说明：https://learn.microsoft.com/cpp/windows/deployment-in-visual-cpp
运行库的版权及许可条件由 Microsoft（微软）保留；原文件中的署名与版权信息未改动。

许可证全文随附于 InnoSetup-LICENSE.txt。

官方地址：https://jrsoftware.org/

安装包内置模型的名称、来源、固定修订版本及每个文件的 SHA256（内容校验值）

固定下载修订及核查说明分别见 ChineseModel-README.md、Apache-2.0.txt、
model-license-source.json 与 ChineseModel-SOURCE.txt。
