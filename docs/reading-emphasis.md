# 整段高亮与实时设置

## 使用方法

应用设置和提词画面的设置面板都提供“阅读提示”。两处操作同一套全局设置，对所有稿件生效。

- 整段高亮：开启后，正在阅读的整段同时使用当前段颜色，不按单字或句号逐个变色。
- 当前段颜色：默认黄色，可以自行选择；进入下一段前，当前段全部文字保持同色。
- 已读段颜色：默认灰色；提词面板中的“标记已读段落”控制是否使用它。进入下一段后，上一整段一起使用已读颜色。
- 当前字放大幅度：默认 10%，可在 0% 至 15% 之间调整；0% 保留整段变色效果。当前字加粗、下划线仍为独立选项。
- 保存失败时保留当前预览并提示重试，不能把失败显示成已经保存成功。

语音跟随和自动按行模式显示当前位置所在段落的突出效果。自动匀速滚动没有字符阅读位置，因此不显示当前段和已读标记。

段落按原稿人工分段确定，句号和问号不会自行拆段。纯文本换行分段；富文本的段落、列表项等块元素分段，段内软换行仍属于同一段。自动折行只改变显示行数，不改变高亮单位。纯文本空行保留间隔；游标经过段落之间的换行空隙时，上一段保持高亮，直到进入下一段文字。

## 排版规则

正文按最大 115% 尺寸预留空间。正常文字按基础字号显示，当前字在固定位置内放大。

阅读正文列以全稿最宽的人工分行为依据，按实际字体、字距、混合字号和字形安全区测量，再加少量取整余量。所有段落共用这一列宽并水平居中，阅读括线随正文列宽对齐。短稿不会继续占用预设的空宽栏，也不会因只有一两个字而自行缩小字号。窗口不足时按可用宽度折行；放宽窗口后恢复内容宽度。窗口高度与纵向阅读锚点仍沿用已有视觉居中逻辑，顶部留白保留。

改变颜色、突出开关、放大幅度或朗读位置，不重新计算正文换行，也不改变字符点击位置。改变窗口宽度、字体、基础字号、行距等真正影响布局的参数，重新排版。

该规则保留稿件的段落和已有字形格式，不承诺复制原稿在另一种纸张或窗口宽度下的断行。预留空间会降低同屏文字密度，关闭突出开关也继续保留这些位置，以免开关切换时画面跳动。

为容纳斜体侧悬，固定字位还留有侧向余量。旧稿件的负字间距按有效零值显示，界面给出说明；用户调整前不改写原稿件设置。可调整的字距下限为零。

当前位置来自原有的语音对齐或自动按行进度。此次改动只改变显示，不改变语音模型及识别算法。

## 设置保存规则

四项阅读提示设置只保存到全局设置。稿件自己的字号、行距、颜色等旧设置继续独立保存，但不能覆盖四项阅读提示设置。沿用旧存储字段名，升级不重置已有颜色、倍率或稿件设置。

新增设置通过专用局部更新保存，服务端串行完成合并和写入。旧的完整设置快照不会覆盖这四项；显式重置和完整备份恢复仍可以更新它们。界面在保存期间保留较新的调节值，避免旧响应把画面改回去。

普通全局设置、阅读提示设置和重置按用户操作顺序保存。重新加载不会覆盖当前连接中正在等待保存的新选择。重置失败时保留完整的待保存选择，重试也保留之后修改的字号、主题和语音模型。连接恢复后会主动读取服务端当前设置，同时保留本地尚未保存的阅读提示预览。

桌面存储在文件替换成功后才确认缓存；写入失败的值不会混入其他保存。稿件与文件夹的完整读取、修改、保存共用业务队列，防止连续设置写入时并发稿件操作互相覆盖。

## 开发环境

沿用上游锁定的 Flutter（跨平台开发框架）3.44.1 和依赖版本。依赖锁定文件使用国内镜像地址，安装依赖时必须保持相同地址，并要求严格遵守锁定文件，避免无关依赖升级。

```powershell
$env:CI = 'true'
$env:PUB_HOSTED_URL = 'https://pub.flutter-io.cn'
flutter --suppress-analytics pub get --enforce-lockfile
flutter --suppress-analytics analyze --no-pub lib test
flutter --suppress-analytics test --no-pub
flutter --suppress-analytics build windows --release --no-pub --dart-define=APP_VERSION=1.7.4
```

上面的自动化环境标记使开发工具跳过云主机环境探测，不影响应用运行。静态检查明确覆盖应用与测试目录，避免把项目目录内另行存放的开发工具及其依赖缓存也当成应用源码检查。

## 验证范围

专项验证覆盖全局设置保存、稿件覆盖隔离、快速连续调整、保存失败重试、输入范围、当前段与已读段颜色优先级、跨软换行和自动折行的整段变色、固定布局、字符点击定位、中文与混合字号、全稿最宽行的稳定测量，以及调节外观时识别会话和当前位置不重置。

实际验证结果在合并请求中记录。麦克风识别准确率仍需使用目标电脑、麦克风和实际稿件进行现场朗读验收。
